## 🎯 About This Tool

Large language models often stop working when a chat session reaches its limit. This tool solves the problem of losing your long conversations. It grabs your chat log from the LMArena website and saves the text into a clean Markdown file. You keep your progress and research without losing data.

## 🛠️ System Requirements

This tool functions on any Windows computer. You need the following items installed before you begin:

1. A modern web browser like Google Chrome, Microsoft Edge, or Mozilla Firefox.
2. The Google Chrome browser is the recommended choice for best results.
3. Access to the LMArena website.

## ⚙️ Setting Up the Script

Preparation ensures the script works as expected. Follow these steps to prepare your browser.

1. Open your web browser.
2. Open the Extensions manager. In Chrome, type chrome://extensions in the address bar.
3. Turn on the switch for "Developer mode" in the top right corner.
4. Click the button that says "Load unpacked."
5. Select the folder you extracted from the download in the previous step.

The browser now recognizes the tool as an active extension.

## 🚀 Running the Export

Now that the tool is ready, you can save your chats.

1. Navigate to the LMArena website.
2. Open the chat session you want to save.
3. Click the puzzle piece icon in your browser toolbar.
4. Select the LMArena history exporter from the list.
5. Click the "Export" button inside the tool menu.
6. Your browser will download a file named with the date and time.

This file contains your full chat history in text format. You can open this file with any text editor or note-taking app that supports Markdown.

## 📝 Frequently Asked Questions

### Does this tool send my data to a server?
No. The script runs entirely inside your browser. No data leaves your computer during the export process.

### Can I save chats that are very long?
Yes. The script handles long conversations by grabbing all visible text from the chat window.

### Where do the files go?
The browser saves the exported files to your default Downloads folder. You can move these files to any folder you prefer.

### What if the export fails?
Refresh the LMArena page and try the process again. Ensure you are logged into your session before you start the export.

### Do I need to pay for this tool?
No. This tool is free to use.

## 💡 Best Practices for Use

Save your chats often. If you work on long projects, export your history every time you finish a task. This creates a backup in case you accidentally refresh the page or clear your browser cache.

Store your exported Markdown files in a cloud-synced folder like OneDrive or Google Drive. This protects your work if your computer fails. Use a Markdown viewer to organize these files into categories or projects.

## 🚧 Troubleshooting

If you encounter issues, check these common fixes:

* Restart your browser: Sometimes the extension needs a refresh to detect the chat window correctly.
* Browser updates: Ensure your browser is up to date. Outdated software causes compatibility issues with web tools.
* Clear cache: If the button does not appear, clear your browser cache and restart the session.
* Permissions: Ensure the extension has permission to run on the LMArena website.

## 📚 Understanding Markdown

The files you create use the Markdown format. This is a plain text format that supports formatting like bold text, headings, and lists. You can view these files in Notepad, but tools like Obsidian, Typora, or Notion display them with better visual style. 

The goal of this format is to ensure you can always read your data even if the tool stops working in the future. Text files are the most reliable way to store information for the long term.
